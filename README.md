# Módulo 2 · Unidade 1 — Vetorização e Embeddings para Busca Semântica

Página didática interativa de apoio aos alunos do **Curso de Formação em IA Generativa**.

## Sobre esta Unidade
Esta unidade explica como textos são convertidos em vetores numéricos (*embeddings*), por que a proximidade geométrica representa significado, como funcionam a similaridade de cosseno, busca léxica vs. densa, *chunking* com sobreposição, índices ANN e busca híbrida.

### Recursos da Aplicação
- **Simulador Visual Dinâmico**: Acompanhamento animado do fluxo de vetorização, indexação e busca por similaridade.
- **Conteúdo Interativo**: Tópicos com explicações *Do Zero*, *Na Prática*, *Atenção / Risco* e *Ponto-chave*.
- **Quiz de Fixação**: 10 perguntas com feedback imediato e explicação.
- **Jogo da Memória**: Combinação de conceitos e definições da unidade.

## Stack Tecnológica
- **Next.js** (App Router com `output: "export"` para deploy estático)
- **Tailwind CSS**
- **Lucide React**

## Como executar localmente
```bash
npm install
npm run dev
```

## Publicação na Vercel
Importe o repositório no GitHub, selecione o diretório `MOD4/M2U1-WEB` como **Root Directory** e faça o deploy (sem necessidade de banco de dados ou variáveis de ambiente).
